# EcoTech Inventory

Gestión de inventario sostenible para EcoTech Solutions — React + TypeScript (Vite) + Supabase.

## Puesta en marcha

```bash
npm install
cp .env.example .env   # completa VITE_SUPABASE_URL y VITE_SUPABASE_ANON_KEY
npm run dev
```
